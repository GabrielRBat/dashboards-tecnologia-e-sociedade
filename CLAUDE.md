# CLAUDE.md

Ao iniciar qualquer sessão neste projeto, leia obrigatoriamente, nesta ordem:

1. `AGENT.md` — instruções de trabalho do agente (fluxo obrigatório para alterações de código).
2. `context.md` — contexto do projeto: objetivo, decisões de arquitetura e estado atual.
3. `changelog.md` — histórico de mudanças do projeto.

Siga estritamente o procedimento definido em `AGENT.md`: alterar → testar → corrigir → testar novamente → revisar → atualizar toda a documentação (incluindo README) → pedir permissão ao usuário antes de `git commit` e `git push`.
